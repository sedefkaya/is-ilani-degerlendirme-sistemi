# İş İlanı Değerlendirme Sistemi

Bu proje, ulusal staj kapsamında geliştirilmiş bir **web tabanlı iş ilanı değerlendirme sistemidir**. Kullanıcılar iş ilanlarını görüntüleyebilir, değerlendirebilir ve ekleyebilir. Proje tamamen frontend teknolojileri ile geliştirilmiştir.

---

## Özellikler

- İş ilanlarını listeleme ve detay görüntüleme
- İş ilanı ekleme ve düzenleme
- Kullanıcı bazlı değerlendirme (puanlama ve yorum ekleme)
- Basit ve kullanıcı dostu web arayüzü

---

## Kullanılan Teknolojiler

- **Frontend:** HTML, CSS, JavaScript
- **Versiyon Kontrol:** Git, GitHub
